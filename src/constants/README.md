# Constants Directory (`/src/constants/`)

Contains static prompts, workspace initialization constants, and Python documentation reference strings.

## File Registry

- `agentPrompts.ts`: Core prompt fragments, preambles, and default system prompt instructions for built-in AI agents.
- `initialWorkspace.ts`: Initial workspace seeding file structure and default welcome documents (`WELCOME.md`, sample scripts).
- `workspacePythonDocs.ts`: Documentation reference guide for the `workspace.py` helper library (`workspace.llm`, `workspace.fs`, `workspace.agent`, `workspace.tools`).
