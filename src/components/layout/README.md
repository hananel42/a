# Layout Components Directory (`/src/components/layout/`)

Contains shared header, navigation, help drawer, notification toast, and print layout styling components.

## Component Registry

- `Header.tsx`: Context header component for document editors and workspace viewports.
- `Toolbar.tsx`: Formatting toolbar component for Markdown text formatting and element insertions.
- `HelpDrawer.tsx`: Collapsible side drawer displaying Markdown syntax cheat-sheets and platform shortcuts.
- `NotificationToast.tsx`: Floating system alert toast component displaying temporary success and error notifications.
- `PrintStyle.tsx`: Global print stylesheet overrides for document exporting and printing.
- `index.ts`: Barrel export exporting layout components.
