# Core TypeScript Types Catalog (`/src/types/`)

This directory acts as the central source of truth for the platform's static type declarations, schemas, and custom type definitions. It promotes strict type safety and modular data modeling.

## Directory Structure

- `agent.ts`: Type models representing agents, chat sessions, interactive messages, sandboxed tool call status updates, and user credentials.
- `workspace.ts`: Virtual and physical workspace filesystem schemas, file node descriptors, and host connection metadata.
- `index.ts`: Standard UI routing structures, editor view mode options, and markdown parsing themes.
