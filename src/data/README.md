# Data Presets Directory (`/src/data/`)

Contains static default profiles, model lists, workspace templates, and Markdown syntax cheat-sheet datasets.

## File Registry

- `defaultAgents.ts`: Built-in agent workforce definitions (Manager Agent, Python Developer, Code Architect, Research Analyst, File Organizer).
- `models.ts`: Fallback LLM model definitions, provider profiles, and endpoint presets.
- `templates.ts`: Starter workspace project templates (Data Analysis, Python Package, Multi-Agent System, Web App).
- `cheatsheet.ts`: Markdown syntax guide cheat-sheet dataset used in the help drawer.
